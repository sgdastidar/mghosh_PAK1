**1. allapo\_training\_AE\_model.ipynb**



This script contains the code used to train and evaluate the apo-based autoencoder model.



The script:



a. Reads the residue–residue distance matrix generated from the apo PAK1 molecular dynamics trajectory and checks the input data for non-numeric values and missing values.



b. Randomly divides the apo dataset into a training subset (80%) and a held-out testing subset (20%) using a fixed random state.



c. Constructs a symmetric multilayer autoencoder using the MLPRegressor implementation of scikit-learn. The dimensions of the encoder layers are successively reduced to one-half, one-quarter, one-eighth, and one-sixteenth of the input feature dimension, followed by a symmetric decoder.



d. Trains the model using the apo training data as both input and reconstruction target and saves the trained autoencoder model in .joblib format.



e. Records and plots the autoencoder training-loss profile.



f. Reconstructs both the apo training and held-out testing datasets and calculates the distance input–output difference (DIO) for every residue-pair feature as:



DIO = input distance − reconstructed distance.





**2. test\_three\_holo\_using\_trainedmodel.ipynb**



This script applies the previously trained apo autoencoder model to the three inhibitor-bound systems: PAKPV, PAKOQ, and PAKOR.



The script:



a. Loads the saved apo-trained autoencoder model.



b. Applies the same apo-trained model to each inhibitor-bound dataset without retraining or modifying the model parameters.



c. Reconstructs the residue–residue distance features of PAKPV, PAKOQ, and PAKOR and calculates DIO values for each feature and trajectory frame.



d. Calculates DIO for the complete inhibitor-bound dataset as well as defined data subsets and generates the corresponding DIO output matrices and normalized distributions.



**3. feature\_importance.ipynb**



This script has the codes used to quantify the importance of individual residue-pair features from the DIO matrices generated by the apo-trained autoencoder.The same script is applied independently to the PAKPV, PAKOQ, and PAKOR DIO datasets.



The script:



a. Reads the DIO matrix generated for an inhibitor-bound PAK1 system.



b. Converts the DIO values to their absolute magnitudes so that deviations in either direction from the apo-trained reconstruction contribute to feature importance.



c. Calculates the importance of each residue-pair feature as the mean absolute DIO across all analyzed trajectory frames.



d. Ranks the residue-pair features in descending order of their mean absolute DIO values.



e. Writes the ranked feature list and corresponding importance values to an output text file for subsequent comparative analysis.



4\. **feature-comparison.ipynb**



This script compares the highest-ranking autoencoder-derived residue-pair features among PAKPV, PAKOQ, and PAKOR.



The script:



a. Reads the ranked feature-importance files generated independently for the three inhibitor-bound systems and selects a user-defined number of top-ranking features.



b. Decodes the numerical feature identifiers into their corresponding residue pairs and maps the DIO residue indices to the residue numbering used throughout the structural analyses.



c. Identifies residue-pair features that are common to all three systems, shared between pairs of systems, or unique to individual inhibitor-bound systems.



d. Compares the importance values of residue-pair features shared among the three systems and calculates changes in feature importance across the PAKPV → PAKOQ → PAKOR series.



e. Determines the individual residues represented among the highest-ranking residue-pair features and calculates how frequently each residue occurs within the selected feature set.



f. Calculates residue-level importance scores by accumulating the importance values of residue-pair features containing each residue.



g. Classifies residue-frequency changes across the inhibitor series as increasing, decreasing, unchanged, or non-monotonic.



h. Generates tables and graphical summaries of feature overlap, residue overlap, residue-frequency changes, and the importance of features and residues shared among the inhibitor-bound systems.



**Input data**



The principal input for first two scripts consists of residue–residue distance matrices generated from the molecular dynamics trajectories. Each column represents a residue-pair distance feature and each row represents an individual MD trajectory frame.
